Imagens de fundo da interface. Você pode colocar mais imagens (`.jpeg`/`.png`) nesta pasta e escolher entre elas na interface.

Os fundos incluídos aqui são gradientes simples gerados para este repositório (sem terceiros).
`ceiling-window-room-night.jpeg` é o fundo padrão que a interface procura; troque-o por outra imagem se quiser.
